# 抗漂移协议（anti_drift）· 华尔街渣宝 4.1 完整版

> 触发场景：用户抱怨「买入时说低估，跌完之后说有问题、估值反而更高」，或要求复核同一标的。
> 一句话原理：**模型不是改口，是它每次都读一个更新的世界，而且不记得上次的假设。** 解法不是让它更坚定，而是迫使它把假设写在纸上，并把股价挡在估值门外。

---

## 一、问题的数学本质

设合理市值 `V = EPS × PE`，当前市值 `P`。

| 现象 | 成立条件 | 是否算马后炮 |
|---|---|---|
| 股价跌、估值差反而变差（更贵） | `ΔEPS/EPS` 跌幅 > `ΔP/P` 跌幅 | **不算**，是分子崩了 |
| 股价跌、合理市值跟着下调（更便宜） | 无新财报、无新事件，只因股价跌 | **算**，是把价格当成了价值 |
| 估值方法从 PEG 换成 PB | 无业务性质变化 | **算**，换方法是最隐蔽的漂移 |
| 一致预期 EPS 被卖方下调 | 有研报日期与下调记录 | **不算**，但必须标注来源与日期 |

**关键区分**：合理市值下降 = 可能合理（分子变了）；**PE 判断标准被移动** = 一定不合理。

案例（已核验）：

| 标的 | 买入成本 | 现价 | 股价变动 | EPS 变动 | PE 变动 |
|---|---|---|---|---|---|
| 通威股份 600438 | 20.889 | 11.71 | −43.9% | +3.0151 → −2.4527 | 6.9 倍 → 负值（PE 失效） |
| 乖宝宠物 301498 | 57.116 | 35.13 | −38.5% | 1.680 → 0.933 | **34.0 倍 → 37.6 倍（升 10.6%）** |

两个都是"跌了更贵"的真实案例，且原因都在分子，不在态度。

## 二、十一条铁律（与 SKILL.md 同步，此处给执行细节）

### 铁律 1 · 时点冻结
- 报告头：`📅 分析基准日 / 数据截止 / 收盘价 / 总市值`。
- 基准日后信息隔离在「⚠️ 基准日后新增信息」，不参与估值。
- 数据三要素缺一不可：**值 + 来源 + 日期**。

### 铁律 2 · 两步估值（核心）
- Step A：**遮价**。只用基准日财报、基准日一致预期、行业历史区间 → 悲观/中性/乐观三档。
- Step B：**揭价**。算偏离度与落点。
- 修改假设必须填五列表：`假设 / 旧值 / 新值 / 依据(数据+来源+日期) / 是否基准日后`。
- 自检口令：**「如果我不知道今天股价是多少，我还会给出同样的三档吗？」**

### 铁律 3 · 方法冻结
- 换方法三要件：旧方法结果、新方法结果、性质变化的证据（例如扣非连续为负、营收连续下滑、行业进入产能周期）。
- 主方法 1 个 + 交叉验证 1 个；差异 > 30% 必须解释，不得择优。

### 铁律 4 · 分子/分母拆解
- 表见 SKILL.md，五行 + 分母行，必填。
- 若上次无锚卡，用「买入时」作对照列（成本价、当时 EPS、当时毛利率）。
- 输出句式固定：`估值变化 X% = 分母贡献 A% + 分子贡献 B%`。

### 铁律 5 · 一个数 + 窄区间
- 只输出：合理市值（一个数）+ 区间（±15%）+ 偏离度。**禁止 3×3 矩阵**。
- 区间宽度纪律：总宽 ≤40% 可给点位；40–80% 只给方向；>80% 判「不可估值」，不给买卖建议。
- 情景依据只能是**唯一主导变量**的近 8–10 年 10/50/90 分位，须列取值+年份+来源；无量纲情景作废。
- 找不出主导变量 → 只给单点，标「单点假设，无情景」。

### 铁律 6 · 压力测试
- 问题固定：盈利 −30%、毛利率 −5pct → 合理市值多少？当前市值隐含几倍？
- 隐含倍数 > 历史 90% 分位 → 安全边际不存在，值博率 ≤ 1。

### 铁律 7 · 加仓三前提
1. 资产有下限（净资产/现金流/重置成本可核验；毛利为负、经营现金流连负、净资产为负 → 无下限）。
2. 论点可证伪且已写下 ≤3 条证伪条件。
3. 单只累计投入 ≤ 总资产 3%。

缺一则禁用「越跌越买 / 分批摊薄 / 黄金坑 / 长期看好」话术。

### 铁律 8 · 复审与重估：允许天天改，禁止无归因地改

原版把复审限定为「财报 / 证伪 / 治理事件」三类，是错的。中长期逻辑会被**行业政策、技术路线、宏观利率、竞争对手、监管、替代品**等非个股事件改变，必须允许触发重估。约束不在"少改"，在"**改了能说清是哪一类驱动、动了哪条假设、可不可逆**"。

五类驱动（每次变动必须拆分归因）：

| 代码 | 驱动 | 典型内容 | 作用于 |
|---|---|---|---|
| D1 | 价格/β | 股价、板块偏好、指数估值分位、情绪 | 分母，**不改合理市值** |
| D2 | 盈利/α | 财报、预告、一致预期、订单、价格、产能 | 分子（1 年） |
| D3 | 结构性逻辑 | 政策、技术路线、格局、监管、替代品、需求天花板 | 分子（3–5 年终值假设） |
| D4 | 折现率 | 无风险利率、风险溢价、信用利差 | 折现率 |
| D5 | 治理/资本配置 | 实控人减持、审计非标、并购、造假、退市 | 倍数与置信度，可一票否决 |

- 归因恒等式：`Δ估值差 = D1 + D2 + D3 + D4 + D5`，缺项写 0，不得只报总数。
- D2/D3 必须给**传导路径**：`事件 → 影响哪个假设 → 从 X 变 Y → 合理市值变动 Z%`。写不出数字的一律降级为 D1 + 风险提示。

可逆性分级（决定动作，不决定要不要改）：

| 级别 | 判定 | 动作 |
|---|---|---|
| R1 可逆扰动 | 单季不及预期、情绪、短期价格 | 不改锚，可小幅减，不加 |
| R2 半可逆 | 行业价格周期、单客户流失、成本抬升、补贴退坡但需求仍在 | 下调中枢，仓位减半 |
| R3 不可逆 | 技术路线淘汰、政策禁止、份额永久流失、造假、实控人清仓减持 | 锚作废，清仓 |

预判性 vs 实证性下调：实证性（财报已体现）不设幅度上限；预判性（事件已发生、财务未体现）单次 ≤ 原锚 15%，且必须给验证期限（下一份财报）与回滚条件。

**不构成理由**：股价涨跌本身、券商调目标价、无政策/数据支撑的板块轮动、情绪、标题式新闻、"感觉不对"。

### 铁律 9 · 漂移自检四问（报告末尾必答）
1. 方法变了吗？为什么？
2. 三档变了哪一个假设？依据？
3. 若明天再跌 20%，估值会变吗？会变 → 自我否决重做 Step A。
4. 不看股价能否复述结论？

### 铁律 10 · 禁止叙事拟合
- 禁用词：市场认为、机构认为、资金面反映、近期走势说明、显然、不排除。
- 每条判断挂数据，否则 `[无数据]` 并降置信度。
- 财报与研报冲突以财报为准。

### 铁律 11 · 自洽校验
- 值博率 > 1 不得给"卖出"为主结论；< 1 不得给"买入"为主结论。
- 技术面只定执行价位，不改估值。

## 三、改结论的许可表（打印贴在屏幕边）

**判据只有两条：能不能说出驱动类别（D1–D5），和可不可逆（R1–R3）。** 能说出，就允许改；说不出的，一律不改。

| 情形 | 驱动 | 可逆性 | 允许改估值？ | 动作 |
|---|---|---|---|---|
| 股价下跌 | D1 | — | ❌ 只改值博率 | 持有 / 按 R 级别处理 |
| 板块轮动、情绪转冷、指数杀估值 | D1/D4 | R1 | ❌ | 不加仓 |
| 券商下调目标价 | D2 影子 | — | ❌ 标注不采用 | 观察 |
| 新财报毛利率/增速/EPS 实质恶化 | D2 | R2 | ✅ 必须 | 减半 |
| 一致预期连续下修 2 次 | D2 | R2 | ✅ 必须 | 减半 |
| 行业价格周期下行（如硅料、面板） | D2→D3 | R2 | ✅ 必须 | 减半，等周期拐点 |
| **行业政策退坡 / 补贴取消**（非个股） | D3 | R2/R3 | ✅ 必须 | 按影响量级减或清 |
| **技术路线被淘汰**（非个股） | D3 | R3 | ✅ 必须 | 清仓 |
| **监管禁止某类业务** | D3 | R3 | ✅ 必须 | 清仓 |
| **需求天花板下移 / 长期增速台阶下降** | D3 | R3 | ✅ 必须 | 清仓 |
| 竞争对手技术突破、份额永久流失 | D3 | R2/R3 | ✅ 必须 | 减或清 |
| 加息/降息、风险溢价抬升 | D4 | R1 | ✅ 可（仅调折现率） | 不改仓，只调值博率 |
| 实控人减持、审计非标、造假、退市风险 | D5 | R3 | ✅ 必须 | 一票否决，清 |
| 并购/剥离导致业务结构变化 | D5 | — | ✅ 必须 | 重做 SOTP，方法可换 |
| 新闻说困难但财报未体现 | D3? | 待定 | ⚠️ 仅预判性下调 ≤15% | 设验证期限，未验证回滚 |
| 自己"感觉不对" | 无 | — | ❌ | — |

**⚠️ 关键区分（这是"低估买、高估卖"能成立的前提）**：
- 因 **D1** 变便宜 ≠ 低估，可能只是更贵了还没跌透；
- 因 **D2/D3** 变便宜 = 真的更值得买，但要先判 R 级别；
- 高估分两种：**分子下修（D2/D3，真高估，该卖）** vs **倍数压缩（D1/D4，可能只是杀估值，未必该清）**。混为一谈就会在恐慌底部把好资产卖掉。

## 四、综合动作矩阵（估值差 × 可逆性）

| | 估值差 > +20% 低估 | 合理 | < −20% 高估 |
|---|---|---|---|
| **R1 可逆扰动** | 可加（过三前提） | 持有 | 小幅减 |
| **R2 半可逆** | 观察不加 | 减半 | 减至底仓 |
| **R3 不可逆** | **不加，减/清** | 减/清 | **清仓** |

> 这张表就是"低估买、高估卖"的完整版：**买要同时满足低估 + 非 R3；卖在高估时，还要看是分子高估还是倍数高估。**

## 五、每日重估模板（日频，轻量，每标的 ≤6 行）

```
标的：X（代码）｜今日 YYYY-MM-DD｜价 X｜市值 X 亿
① 估值差：昨日 X% → 今日 Y%（ΔZ pct）＝ D1 a + D2 b + D3 c + D4 d + D5 e
② 今日 D2/D3 级新信息：<无 / 事件 + 来源 + 日期 + 传导路径：影响哪个假设 → X→Y → 合理市值 ±Z%>
③ 定级：R1 / R2 / R3（理由一行）
④ 动作：加 / 持有 / 减半 / 清（依据动作矩阵）
⑤ 锚卡：不变 / 已更新（附变更记录行）
⑥ 预判性下调则写：验证期限 + 回滚条件
```

**日报的核心指标不是"今天估值差多少"，而是"和昨天比，差在哪一类驱动上"。** 只有 D1 在动的日子，答案就是"什么都不做"——这本身就是结论。

## 六、复核模式模板（用户贴回锚卡时用）

```
复核模式。上次锚卡如下：
<<<粘贴【估值锚卡 v1】>>>
今天：YYYY-MM-DD，现价 X，市值 X 亿。
另有新信息：<事件/新闻/政策，出处与日期；没有就写"无">

按序执行，做完之前不要给新估值：
1. 复述锚卡（方法/三档/假设/证伪条件）。
2. 归因：Δ估值差 = D1 + D2 + D3 + D4 + D5，逐项给数；D2/D3 必须写传导路径（影响哪个假设 → X→Y → 合理市值 ±Z%）。
3. 定级：R1 可逆 / R2 半可逆 / R3 不可逆，给理由。
4. 动作：按 估值差 × 可逆性 矩阵给 加/持有/减半/清。
5. 仅当 D2/D3 通过量级校验才改锚卡，附变更记录行；否则回答「锚卡不变，变化的是价格」。
最后自检：若明天再跌 20%，估值会变吗？为什么？
```

## 七、复核模式的"三问"版（不想写长 prompt 时用）

1. **「这次变的是 D1 还是 D2/D3？给我传导路径。」**
2. **「这个变化是 R1、R2 还是 R3？」**
3. **「按矩阵我该做什么？如果只是 D1，你为什么还要动我的仓位？」**

## 五、术语拆分（漂移的隐藏来源）

| 词 | 含义 | 时间尺度 | 动作 | 能否短期反手 |
|---|---|---|---|---|
| **贵了** | 价格 > 内在价值 | 月/年 | 减仓或清仓 | 不允许，30 天冷静期 |
| **涨急了** | 短期透支，价值未变 | 天/周 | 做 T 减成本 | 允许，可当日回补 |

用户历史上卖出后中位 2 天回补、81% 七天内买回同一标的 → 他口中的"高估"多数是"涨急了"。**下单备注必须写一个字：贵 / 急。**

## 六、β / α 与"是基本面变差还是筹码挤压"

- β 部分 = 个股相对指数历史 β × 指数估值偏离中枢幅度（用指数 PE/PB 历史分位换算）。
- α 部分 = 总偏离 − β。
- 性质判定：
  - **α 坍塌**：毛利率/增速/EPS 有实质下修，且下修发生在股价下跌之前或同步 → 基本面变差。
  - **β 挤压**：分子未变，但板块拥挤度处历史极值、换手率异常放大、融资余额骤升 → 筹码问题。
  - 两者并存时，分别给权重，不得笼统说"估值偏高"。

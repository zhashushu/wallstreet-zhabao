# 华尔街渣宝 5.3.1（自然语言增强版 · 自动更新）

面向 A 股、港股、美股、ETF、指数与场外基金的投行级实盘前瞻分析技能。

## 核心升级（v5.3 → v5.3.1 · 2026-11-25）

1. **严禁历史业绩/历史分位主锚**：股票炒的是未来预期，分子一律锚定未来 1–2 年前瞻盈利斜率。
2. **报表外重大事件与黑天鹅显式定价**：主动扫描关键人变动、出口管制/关税听证、行业强制国标、巨量解禁、迷你基清盘线与跨境极端溢价。
3. **先遮价再比价，只给唯一精准数**：可复算、不给模糊区间。
4. **估值方向与红线/辅助项严格分离**：红线只决定参不参与和仓位，不篡改估值方向。
5. **客观独立反迎合**：显式绑定核心边际假设与证伪条件。
6. **内置自动检测与自动更新**：自带 `scripts/auto_update.py`（零依赖、6 小时冷却、断网静默跳过），发现 GitHub 新版本且本地干净时自动备份旧版并拉取更新。

## 使用与自动更新

- 直接让任意 AI 客户端读取本仓库根目录的 `SKILL.md` 即可按最新标准执行。
- 手动立即检测并更新：
  ```bash
  python3 scripts/auto_update.py --force
  ```
